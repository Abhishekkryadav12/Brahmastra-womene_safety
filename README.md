# 🛡️ Brahmastra – Women Safety

### A Smart Digital Platform for Women's Safety

Brahmastra Women Safety is a web-based project focused on promoting women's safety through digital technology. The project aims to provide a platform that supports women's security, awareness, and access to safety-related resources.

## 🌟 Project Overview

Women's safety is an important concern in today's world. Brahmastra aims to use modern web technologies to develop a digital solution that can help women access safety-related services and information.

The project is developed with a frontend and backend structure to support its application functionality.

## 🎯 Objectives

- Promote women's safety and security.
- Develop an accessible and user-friendly web application.
- Use modern web technologies to build a digital safety platform.
- Provide a foundation for future safety-related features.
- Encourage awareness about women's security.

## ✨ Key Highlights

- Web-based application.
- Frontend and backend project architecture.
- Modern user interface development.
- Responsive web development approach.
- Expandable architecture for future improvements.

## 🛠️ Technologies Used

- **Vite** – Development and build tooling.
- **TypeScript** – Application development configuration.
- **Tailwind CSS** – Styling and UI configuration.
- **JavaScript** – Supporting application scripts.
- **Node.js / npm** – Package and dependency management.

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Abhishekkryadav12/Brahmastra-womene_safety.git
```

### 2. Open the project directory

```bash
cd Brahmastra-womene_safety
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Check `package.json` for available scripts and backend-specific setup instructions.
